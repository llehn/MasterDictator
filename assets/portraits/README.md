# Central Committee portraits

Nine caricature portraits for the Master Dictator app and website. Each one has an invented name that echoes a historical dictator. Never show the real name (`basedOn`) to users. It is in the manifest only so developers know who each one is.

## Files

| File | What it is |
|---|---|
| `portraits.json` | Manifest: id, display name, title, quote, description (alt text) and file paths for every portrait |
| `<id>.svg` | Figure only: head and shoulders, transparent background, no microphone. The master artwork |
| `<id>_poster.svg` | Same figure on the red sunburst background with a microphone, in the website's poster style |
| `png/<id>_512.png`, `png/<id>_1024.png` | The figure rendered to PNG with transparency, 512×640 and 1024×1280 |

All artwork has a 4:5 aspect ratio (viewBox `0 0 400 500`). Heads sit in the same position in every portrait, so they line up in a grid or a carousel. The body is cut off flat at the bottom edge.

Ids are lowercase with underscores, so they are valid Android resource names as they are.

## Android

Use the PNGs: copy `png/<id>_1024.png` to `res/drawable-nodpi/<id>.png` and scale it in the layout. Don't import the SVGs with Android Studio's Vector Asset tool: the artwork uses dot-pattern shading that VectorDrawable does not support.

Read the names, titles and quotes from `portraits.json`, or copy them into string resources.

## Website

Reference the SVGs directly (`<img src="assets/portraits/<id>_poster.svg">`) or inline them.

## Changing the artwork

Don't edit the SVGs or PNGs by hand. They are generated by `tools/portraits/generate.js`:

```
node tools/portraits/generate.js
```

This rewrites everything in this folder. It needs Node.js, plus Microsoft Edge or Chrome for the PNGs (set `BROWSER` to the executable's path if it is not found).
